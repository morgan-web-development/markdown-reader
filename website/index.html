Built for reading, not editing

Markdown Reader turns local .md files into a clear reading experience.

  • Open any Markdown file Browse your PC or drag and drop a file into the window.
  • Clean reading view Headings, lists, code, tables, and quotes rendered for comfortable reading.
  • Light and dark mode Switch themes anytime. Your preference is remembered.
  • Private by design Files stay on your computer. No account, no cloud upload, no tracking.
